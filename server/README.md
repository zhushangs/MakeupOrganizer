# Legacy: ASP.NET Core version (no longer used)

This was the original backend, run on a PC with `start.bat`. The app now runs on Cloudflare (`worker/`), and this version is **not used or maintained anymore**. See the main README, "Legacy PC version".

The one part that is still used: `MakeupOrganizer.Api/wwwroot/` is the frontend build output that the Cloudflare Worker serves. Don't delete it.
